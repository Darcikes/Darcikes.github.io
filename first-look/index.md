## 📐 这个栏目是什么

面向**刚接触一个新领域**的读者。不假设任何前置知识，先讲「这是什么、为什么需要」，再讲「怎么用」。

写作上守三条规矩：

| 规矩 | 说明 |
| ---- | ---- |
| **类比优先** | 每个抽象概念配一个生活类比（快递、查号台、传送带），类比对了概念就懂了 |
| **表格优先** | 对比、清单、步骤一律表格化，不用大段文字堆砌 |
| **实测优先** | 能放真实命令输出的就放真实输出，不编造数字 |

每篇结尾都有术语速查表 + 一句话总结，目标是**带着结论离开**。
